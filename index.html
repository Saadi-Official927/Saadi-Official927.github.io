How I build for the bad day

  • The incoming payload is stored before any external call, so a timeout never loses data
  • Explicit timeouts, retries with backoff, and an error branch on every integration
  • Idempotency keys wherever a retry could create a duplicate
  • Failures are visible and replayable, never silent, and I say early when something is going wrong

The shape of most integrations I ship, whether the trigger is a webhook, a form or a phone call.
